# contextree

Un arbre de contexte partageable, routé par IA, injecté à chaque appel — via un serveur MCP et un hook Claude Code. Comme un `CLAUDE.md`, mais **routé** : la bonne fraction, pas tout le fichier.

Repo TypeScript/Node privé `GengAd/contextree`, mainteneur solo (Adrien Buot). Package `@gengad/contextree`.

**Cet arbre est la seule documentation de ce repo.** Il n'y a pas de `CLAUDE.md` ni de fichier de consignes à la racine — le seul `.md` qui y reste est le `README`, une procédure pour un humain. Ce que tu cherches est dans une branche ; si tu ne l'as pas reçue, le catalogue en fin de bloc la nomme, et `get_context` te la donne.
